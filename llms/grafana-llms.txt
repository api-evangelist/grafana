# Grafana

> Grafana is the open-source analytics and monitoring platform that connects to a wide range of data sources including Prometheus, Loki, Elasticsearch, InfluxDB, MySQL, PostgreSQL and cloud providers. Its HTTP API manages dashboards, data sources, alert rules, users, organizations, folders, annotations and teams. Authentication is via service-account tokens / API keys or basic auth.
